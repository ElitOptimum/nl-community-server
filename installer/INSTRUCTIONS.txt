NEMESIS: LOCKDOWN - LOCAL MULTIPLAYER (without the official servers)
=====================================================================

WHAT IS THIS
------------
Unofficial community project, not affiliated with Awaken Realms / Inter Studio.
A legally purchased copy of the game on Steam is required.

The official game servers have been shut down, but the game itself contains
everything needed: a complete server and a local hosting mode that was
switched off. This package switches it on (Serbian instructions: UPUTSTVO.txt).
Nothing is downloaded from the internet and nothing is installed into Windows.
All changes are removed with "Uninstall.bat".

WHAT YOU NEED
-------------
- Windows 10/11
- Nemesis: Lockdown installed through Steam (original game, your account)
- Steam running and logged in
- This folder (NemesisLocal) copied anywhere on your disk, e.g. the Desktop

INSTALLATION (once)
-------------------
0. Install the game through Steam and start it ONCE normally from Steam
   (Steam then installs the required extras, e.g. Visual C++ and DirectX).
   When the main menu appears, quit the game.
1. Open the NemesisLocal folder.
2. Double-click  Install.bat
   - If Windows says "Windows protected your PC": click "More info", then "Run anyway".
   - The script finds the game folder by itself. If it can't, it will ask you
     to type the path (e.g. D:\SteamLibrary\steamapps\common\Nemesis - Lockdown).
3. When it says DONE, close the window.

STARTING THE GAME (every time)
------------------------------
1. Steam must be running (logged in).
2. Double-click  Start Nemesis.bat
   - A small black window opens (this is normal, don't close it), then the game.
   - On the FIRST start Windows Firewall may ask about NemesisLDServer:
     tick BOTH boxes (Private and Public) and click "Allow access".
     Public is needed for playing over the internet (Radmin VPN).
3. Play. When you quit the game, the black window closes by itself.

IMPORTANT: If you start the game directly from Steam, solo play works, but the
multiplayer menu says "YOUR GAME IS OUTDATED". For multiplayer always use
Start Nemesis.bat.

HOW TO PLAY MULTIPLAYER
-----------------------
One player is the host, the others join.

HOST:
  PLAY -> MULTIPLAYER -> enter a server name -> CREATE SERVER
  Wait about 20-30 seconds (nothing is shown, this is normal), then:
  PLAY -> SERVERS LIST -> your server appears -> click it -> you enter the lobby.

OTHER PLAYERS:
  PLAY -> SERVERS LIST -> click the host's server -> lobby.
  Note: the list searches for servers on the LOCAL NETWORK (same router/WiFi).
  If you are not in the same house / on the same WiFi, see the next section.

PLAYING OVER THE INTERNET (Radmin VPN)
--------------------------------------
The game only looks for servers on the local network. The free program Radmin VPN
creates a "virtual local network" over the internet, so the game thinks you are
all on the same WiFi. Nothing needs to be set up on the router.

ONCE (all players):
  1. Download Radmin VPN ONLY from the official site:  https://www.radmin-vpn.com
     and install it (Next, Next, Install).
  2. Start Radmin VPN and click the "Power" button (top left) so it is on.

The HOST creates a network (once):
  3. In Radmin VPN click "Create Network".
  4. Enter a network name (e.g. NemesisMark) and a password, click "Create".
  5. Send the name and password to the other players (Discord, WhatsApp...).

The OTHER PLAYERS join (once):
  6. In Radmin VPN click "Join Network".
  7. Enter the host's network name and password, click "Join".
  8. In the Radmin window you should see each other with a GREEN dot.
     If the dot is grey or yellow, wait a bit or restart Radmin VPN.

EVERY TIME YOU PLAY:
  1. EVERYONE turns Radmin VPN on first (green dots).
  2. ONLY THEN the host starts the game with Start Nemesis.bat and creates the
     server (PLAY -> MULTIPLAYER -> CREATE SERVER, wait 30 s, enter the lobby).
     IMPORTANT: if the game was running before Radmin, close it and start it again.
  3. The others start the game with Start Nemesis.bat and go to
     PLAY -> SERVERS LIST -> click the host's server -> lobby.
     If the server doesn't show up, the host can send an INVITE from the lobby.

If the server still can't be seen, check Windows Firewall (see TROUBLESHOOTING).

IN THE LOBBY:
  When everyone is in, the host clicks START GAME.
  If the host is ALONE in the lobby, START GAME starts a solo game (same as SOLO).

SOLO and TUTORIAL work normally.

TROUBLESHOOTING
---------------
- "YOUR GAME IS OUTDATED": you didn't start the game with Start Nemesis.bat, or
  the black window was closed. Close the game and start it again with the .bat file.
- The server doesn't show up in SERVERS LIST: wait 30 s, switch to another tab and
  back to SERVERS LIST. Make sure you are all on the same network and that the
  Firewall allowed NemesisLDServer. Don't click on the empty list (there is a
  solo game button there).
- Over Radmin VPN the server doesn't show up:
  a) Check that everyone has a GREEN dot in the Radmin window.
  b) Host: close the game and start it again (the server must be created
     AFTER Radmin was turned on).
  c) Firewall: Start -> type "Allow an app through Windows Firewall" -> open it
     -> "Change settings" -> find NemesisLDServer and Nemesis -> tick both
     Private and Public -> OK. (Both the host and the other players do this.)
  d) If you use another VPN (e.g. ProtonVPN, NordVPN), turn it off while playing.
- "Unable to create solo game": an old server was left running. Close the game and
  start it again with the .bat file.
- After a Steam update of the game (unlikely, the game is no longer maintained):
  run Install.bat again.

UNINSTALLING
------------
Double-click  Uninstall.bat  - removes all changes (two patch files, steam_appid.txt,
one entry in Engine.ini). The game is as if nothing had been done.

WHAT THE PACKAGE CONTAINS
-------------------------
backend\NemesisLocalBackend.exe  - a small local program that answers the game's
                                   version check (replacement for the shut-down
                                   game server). Runs only on your computer
                                   (127.0.0.1:8888). On first start it creates its
                                   own certificate in backend\cert (this is normal).
paks\client, paks\server         - two small "patch" files for the game (they enable
                                   local hosting and don't touch the original files).
scripts\                         - PowerShell scripts called by the .bat files.
